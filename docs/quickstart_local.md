# Локальная разработка

Ваш новый локальный пайплайн работы на домашнем компьютере стал значительно проще, быстрее и больше не требует постоянного перезапуска Docker. Вот пошаговый процесс:

### 1. Ежедневная разработка и отладка (Максимально быстрый режим)
Для написания и тестирования кода Docker вообще не нужен. Всё запускается на хост-машине:

*   **Шаг 1: Запуск бэкенда (Rust)**
    Откройте терминал в папке `backend/` и запустите:
    ```bash
    cargo watch -x run
    ```
    *При изменении любого `.rs` файла проект автоматически и очень быстро перекомпилируется и перезапустится.*

*   **Шаг 2: Запуск фронтенда (Svelte)**
    Откройте второй терминал в папке `frontend/` и запустите:
    ```bash
    npm run dev
    ```
    *Vite запустит сервер разработки (обычно на `http://localhost:5173`). Благодаря технологии HMR любые изменения в интерфейсе будут мгновенно отображаться в браузере без перезагрузки.*

*   **Шаг 3: Тестирование в браузере**
    Откройте `http://localhost:5173`. Фронтенд автоматически проксирует все запросы к API и WebSocket на ваш локальный Rust-бэкенд (`localhost:8080`).

---

### 2. Проверка сборки в Docker (Перед отправкой кода)
Если вы хотите убедиться, что проект корректно упаковывается в Docker-контейнеры и работает в изолированном окружении:

*   Выполните команду в корне проекта:
    ```bash
    docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d --build
    ```
    *Эта команда локально соберет образы бэкенда и фронтенда из вашего текущего кода и запустит приложение на порту `8081` (без требований к внешнему прокси Traefik).*

---

### 3. Публикация изменений на GitHub
Когда вы убедились, что всё работает:

1. Сделайте коммит изменений:
    ```bash
    git add .
    git commit -m "feat: описание ваших изменений"
    ```
2. Отправьте код на GitHub:
    ```bash
    git push origin master
    ```

После этого **GitHub Actions** автоматически запустит сборку в облаке и обновит готовые образы в реестре (`ghcr.io`). На вашем сервере (или у других пользователей) проект обновится за секунды простой командой `docker compose pull && docker compose up -d` (или автоматически через Watchtower).
